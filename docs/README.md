# Trickster Online — Game Systems Documentation

Trickster Online (also *Trickster: Links to Fantasy*, *Trickster Online Revolution*, *Trickster Online: A New Discovery*, *Trickster Online: Season 2*) was a free-to-play 2D isometric anime MMORPG developed by **Ntreev Soft** (born from Sonori's online-game division), first shown publicly at Tokyo Game Show 2002, launched in Korea on April 10, 2003, in China via gamigo (2004; known locally as 星钻物语 "Star Diamond Story"), in Japan under GCREST (open beta January 21, 2005; 1.2M IDs by 2008; operation passed to Gamepot on July 18, 2012), and in North America on February 23, 2007. All official servers shut down on **January 28, 2014** — the Japanese service ended the same morning at 10:00 JST. A mobile sequel, *Trickster:M*, ran in Korea from May 20, 2021 to February 15, 2024. The game lives on today through community revival servers (LifeTO, PandaTO, CoraTO, xTrickster, OurTrickster, Natural Trickster, Techichi Trickster, and others).

The game is set on **Caballa Island**, where the late billionaire game-company founder Don Cavalier willed his fortune to whoever solves his final masterpiece — a contest that becomes far more than a treasure hunt across 6 story episodes.

This folder documents the game's systems, **one file per system**. All data was gathered via Exa web search from the sources listed at the bottom of each file (primarily the ggFTW Trickster Wiki archive mirrored by LifeTO, Wikipedia, official press releases, community wikis, and Korean sources — namu.wiki, the Korean game press, and Korean player-blog archives).

> **New here?** Start with [00-progression-guide.md](00-progression-guide.md) — the level-ordered walk that shows when each system unlocks and how they feed each other.

> Numbers and rules below reflect the official international/NA version (2007–2014) unless noted. The Korean service ran longer and received exclusive endgame systems (see file 33); revival servers tweak many values (rates, costs, level caps), and server-specific behavior is flagged where relevant.

## Scope notes

- Systems documented here are the **official game systems**, including the Korean service's exclusive endgame content (file 33). Revival-server-only customs (e.g. LifeTO's Angel Guide system and marketplace, PandaTO's Rebirth/Avataring, OurTrickster's Soul System and web auction house) are mentioned only as context, not as separate systems.
- Some minor official functions (tutorial quests, commands) are covered inside the most related file; the interface/shortcut layer and the HP/MP recovery system have their own file (37).
- **Revival-server alterations** (flagged where relevant): LifeTO runs close-to-official rules with higher rates, a Galder→MyShop converter, web storage, questable 4G cards/fuses/AFK-drilling pets, and boss-room level restrictions removed from Tutankhamen through Soki with improved unique drops from boss treasure boxes — it explicitly excludes wings and overpowered equipment. PandaTO and OurTrickster add their own customs (Rebirth/Avataring, web auction house, Soul System, wing fusing).
